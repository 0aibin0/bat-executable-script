## 2. captain 指定专项校验（4 条）

### 2.1 `cd /d` 返回码 —— **captain 裁定制胜，已改**
doc-writer 的纠偏 #2 声称"`cd /d` 到不存在的盘符返回 0"，并把它写进了 M-03 的"易错点"和附录 A。

我按 captain 给的方法独立复测（`analysis/probes_review/r_cd.bat`，每次先 `cmd /c exit 0` 复位）：

```
cd /d "Q:\no_such_dir\LOGS_1"      rc=1  cwd 未变   err: The system cannot find the drive specified.
cd /d "C:\no_such_dir_zz\LOGS_1"   rc=1  cwd 未变   err: The system cannot find the path specified.
cd /d "C:\Windows"                 rc=0  cwd=C:\Windows
cd /d "C:\Windows\notepad.exe"     rc=1  cwd 未变   err: The directory name is invalid.
```

**结论：captain 正确，doc-writer 错。** 根因也与 captain 判断一致——doc-writer 那组探针里 `mkdir` 先成功了，`cd /d` 自然 rc=0，它把"mkdir 成功"误当成了"cd 对不存在盘符也成功"。

已改两处：
- 正文 M-03 的「易错点」→ 换成上面这张实测表，并明确写"**检查 `cd /d` 返回码是可行的**，真正的问题是脚本压根没检查"。
- 附录 A 该行 → 改为「**成立**」，并注明上一版结论已撤销。

### 2.4 `set /a` 八进制 `08→0 / 010→8 / 016→14` —— **写对了；但文档给的修复片段是错的**

```
arg=8 n=8 | arg=08 n=0 | arg=010 n=8 | arg=016 n=14 | arg=018 n=0 | arg=18 n=18
```

**但文档 M-02 的"修复建议"片段照抄会直接失败**。它写：

```bat

```

```bat
set "p3=00!arg!"
set "p3=!p3:~-3!"
set /a "n=1!p3!-1000" 2>nul
```

→ `8/08/1/10/010/18/018` 全部得到 `8/8/1/10/10/18/18`，PASS。
